# Expense Auditor

When activated, read `references/instructions.md` for the monthly expense scan audit framework, SaaS stack audit template, negotiation playbook (renewal, competitor leverage, bundling), and quarterly review report template.

**Trigger keywords:** SaaS audit, subscription audit, expense review, cost optimization, vendor negotiation, software spend, recurring charges.

## Common Anti-Patterns

### 1. Flagging all recurring charges without context
**Symptom**: Flagging all recurring charges without context
**Problem**: Recurring SaaS charges for actively used tools are not waste — flagging them all wastes audit time.
**Solution**: Cross-reference spend against login/usage data before flagging recurring charges. Target zero-login or duplicate-tool spend first.
