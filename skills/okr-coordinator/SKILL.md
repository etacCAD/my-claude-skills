# OKR Coordinator

When activated, read `references/instructions.md` for OKR format (Objective + Key Results), quarterly template, lifecycle workflow (start/weekly/mid-quarter/end), scoring guide, and integration details.

**Trigger keywords:** OKRs, objectives and key results, quarterly goals, KPIs, goal setting, team alignment, quarterly planning, OKR review.

## Common Anti-Patterns

### 1. Setting OKRs that are 100% achievable
**Symptom**: Setting OKRs that are 100% achievable
**Problem**: OKRs should be ambitious enough that 70% achievement is considered strong. 100% completion signals the goal wasn't ambitious enough.
**Solution**: Calibrate key results so that 60-70% achievement at quarter-end is expected. If you're consistently hitting 100%, raise the bar.

### 2. Cascading OKRs top-down without team input
**Symptom**: Cascading OKRs top-down without team input
**Problem**: Imposed OKRs without team ownership create compliance theater — teams report on metrics they don't believe in.
**Solution**: Co-create OKRs with teams after setting company-level objectives. Teams propose their own key results aligned to company goals.
