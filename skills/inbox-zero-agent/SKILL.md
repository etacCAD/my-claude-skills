# Inbox Zero Agent

When activated, read `references/instructions.md` for the full triage framework (Urgent/Important/Standard/Low/Trash), triage decision tree, response templates (meeting request, follow-up, decline), and daily email brief format.

**Trigger keywords:** email triage, inbox zero, email management, draft reply, email brief, email overwhelm, inbox cleanup.

## Common Anti-Patterns

### 1. Archiving without labeling
**Symptom**: Archiving without labeling
**Problem**: Clearing inbox by bulk-archiving destroys the ability to find emails later without a label or folder system.
**Solution**: Apply labels before archiving. Use sender-based or topic-based labels so archived emails remain searchable.
